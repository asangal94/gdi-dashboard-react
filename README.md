# GDI Reporting Dashboard

GitHub Pages-ready React/Vite prototype.

## Latest layout updates

- Inventory Progress is placed on the left.
- Destruction Progress and Project Progress Updates are stacked in the centre.
- SOC 2 Type II Status is placed on the right.
- The overview is designed to keep the four KPI cards and all major sections visible in one desktop presentation screen.
- The Structured and Unstructured Progress title is centred above the two doughnut charts.

## Publish

Upload all files to the repository root. Set **Settings > Pages > Source** to **GitHub Actions**. Every push to `main` republishes the site.
